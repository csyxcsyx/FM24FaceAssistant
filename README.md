# FM24 头像助手

为 Football Manager 2024 的球员、职员和特殊角色匹配头像，支持手动换图、自动补全和恢复原头像包。程序适用于 Windows x64，只读访问游戏进程，不读取或修改存档文件。

## 安装

1. 从 [最新 Release](https://github.com/csyxcsyx/FM24FaceAssistant/releases/latest) 下载 Windows x64 ZIP；可用同页的 `.sha256` 文件校验下载内容。
2. 解压到可写入的文件夹，运行 `FM24头像助手.exe`。
3. 首次运行时可安装随包提供的 `FLAYUS skin 24 YUXIANde`。也可跳过；头像管理仍可使用，但游戏内 UID 显示和工具栏入口需要配套皮肤。

程序已包含 .NET 运行时，无需另行安装。更新时先退出助手，将新版完整解压到空文件夹后启动；保留已有的 `assets` 图库目录和本机用户数据。

也可将新版完整解压到其他目录后启动。同一 Windows 登录会话只运行一个主实例，下载监控也由该实例管理。1.0.3 起支持版本切换：旧实例空闲时正常退出后由新版接管；有任务或子窗口时会提示先完成操作。1.0.2 及更早版本需先从托盘退出，再打开新版。不同副本之间应使用相同的 Windows 权限运行。

移动程序后请从新目录启动一次，助手会更新游戏内入口和唤出协议；随后在 FM 中重载皮肤。使用已有图库后会记住其实际位置，升级可继续复用；删除旧程序目录前，请保留其中的 `assets` 或自定义用户数据目录。

请保留程序目录中的 `FM24FaceAssistant.exe` 和 `FM24头像助手.exe`：前者用于兼容游戏内的旧入口，后者方便日常打开，两者共用同一个程序实例。更新后若按钮没有反应，先从新目录打开助手，等待加载完成，再在游戏中重载皮肤。程序会同时修复其他皮肤中已有的助手入口。

头像分配和设置保存在 `%LOCALAPPDATA%\FM24FaceAssistant`。首次下载的图库和断点默认放在此用户数据目录中，不依赖程序安装位置；设置中可选择空间充足的其他磁盘，升级时会优先续用旧版本 `assets` 中的图库或未完成下载。本地图库不包含在程序下载包或公开仓库中。图库下载、解压和校验均由程序内置完成，无需安装 Python、Pillow 或其他下载工具。关闭助手会保存进度，下次点击“下载 / 接续图库”继续；隐藏到托盘则继续当前任务。下载完成后即可使用，无需重启。

## 使用

**第一次获取头像：**打开“设置与恢复 → 常用”，点击“下载 / 接续图库”。进度窗口会自动打开；程序会下载、解压、校验并加载官方头像包。图库较大，可先在“图库下载与断点目录”选择空间充足的磁盘，点击下载时会直接使用该位置。完成后进入“自动补全”，重新扫描缺图，检查预览后再应用。

“NG_Regens 图库目录”用于选择已经解压好的头像素材，不要选择皮肤、球衣或图标文件夹。若旧版只显示六七百张皮肤图片，升级后直接点击下载即可修复，无需重装游戏或删除存档。断网或退出助手后，原位置的进度仍会保留，下次点击同一按钮继续。

- **手动换图**：搜索姓名或 ID，选人物，再随机重选或点击候选头像预览；点击“应用并刷新游戏”保存并刷新皮肤。
- **自动补全**：扫描缺失头像时会合并更新名单；检查预览后应用结果。优先分配本地区未用头像，再扩展至兼容地区，最后按使用次数复用。也可手动选择其他素材。
- **特殊角色**：为名单中找不到的人物创建角色，填写姓名、UID 和职位后选图并应用。隐藏角色 UID 由当前存档决定，助手不会仅凭姓名推算。
- **主教练头像**：FM 使用单独的个人头像设置。按程序提示导出图片后，在游戏“偏好选择 → 概况 → 改变轮廓贴图”中载入。
- **恢复原头像包**：在“设置与恢复”中恢复助手改动前的外部头像映射。不要手动删除程序生成的恢复备份。

刷新默认快捷键为 `Shift+R`。发送刷新按键成功后，游戏仍需时间重载大型头像包。

## 开发

需要 .NET 10 SDK 和 Windows 桌面开发组件。运行检查（包含本地 HTTP 下载、取消恢复、ZIP 校验及跨进程实例锁）：

```powershell
dotnet run --project Tests/Tests.csproj -c Release
```

打包 Windows x64 自包含版本（需要 PowerShell 7）：

```powershell
pwsh -File maintenance/build-release.ps1
```

输出位于 `artifacts/v<版本号>/`，包含 ZIP 和 SHA-256 校验文件。脚本只从发布输出打包，不复制本机数据配置、图库、头像记录或调试符号。

源码、测试和姓名数据位于项目根目录、`Tests` 与 `Data/Names`；随附皮肤及校验清单位于 `Bundled`。`maintenance` 保留皮肤打包和程序发布脚本。`assets`、`user-data`、本机 `release` 和构建产物不进入版本库；其中的头像分配与恢复备份应保留。

## 资源与隐私

姓名和国籍信息仅在本机用于头像推荐，不会上传。NG_Regens 图库从其官方来源下载，版权归原作者；本项目不随包分发该图库。头像分配、设置和恢复备份保存在本机，不提交到版本库。
